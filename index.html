How it works

Set up one device. Atomic loads the model, sends it paid requests and records your earnings.

Add your device

Install the node on your device. You choose when it is available.

Atomic loads the model

The network assigns a model that fits your verified memory and measured speed.

A user sends a request

Atomic Chat and API traffic is routed to a compatible node while it is online.

You get paid for the work

Completed inference is metered to your earnings. Atomic takes 0% of inference revenue.

Private by design

Requests arrive with nothing that ties them to a person. Your machine does the work and keeps no record of it.

  • Anonymous requests

    Your device gets the prompt, the model and a random number. It never sees the account, the address or the key behind them, and two requests from one person cannot be linked.

  • Nothing is logged

    The text passing through your machine is never written down. That is enforced in the code, not in a policy.

  • Open-source

    The node code is public, so you can verify there is no logging and nothing written to disk.

  • Scrambled before it arrives

    Atomic encrypts emails, phone numbers, card numbers and other personal data before the request is sent.

FAQ

What your device runs, when you can pause it, and how your earnings are counted.

What does my device run?

Atomic assigns one supported model that fits your verified memory and measured speed. The model runs locally through the node agent.

Can I pause the node?

Yes. You choose the work window and can pause at any time. New requests stop routing before the node pauses.

What am I paid for?

Verified availability and completed inference are recorded separately. Live demand, model price, measured speed and uptime determine the final rate.

How is estimated revenue calculated?

The comparison uses output speed × 24 hours × the lowest listed OpenRouter output price. Atomic takes 0%. Actual earnings depend on network demand.

Do I need to buy a new device?

No. Start with a supported device you already own.
